# Smart Record Manager Website

A polished responsive landing page for Smart Record Manager (SRM).

## Run
Open `index.html` in Chrome or Edge.

## Add the Microsoft Store link
Open `script.js` and replace:

const STORE_LINK = "";

with the real Microsoft Store URL.

All Microsoft Store buttons on the website will then use that URL.

## Files
- index.html — website
- style.css — design and responsive layout
- script.js — Store-link configuration and animations
- assets/ — SRM icon and supplied application screenshots
